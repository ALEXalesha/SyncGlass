**SyncGlass 1.3.1: "Run" starts copying right away.**

- "Run" right after a preview no longer checks all move candidates a second time. On the author's tree the preview had already checked hundreds of thousands of moves, then "Run" checked the same pairs again, and the copying started only an hour and a half after pressing it. Now the check results live as long as the scans themselves (15 minutes): "Run" reuses them and starts copying. A file that changed and shows up in a new scan gets a new key and is checked again; "Refresh", the "Skip junk" checkbox, an error and the end of a sync drop the results together with the scans.
- The check runs 128 pairs at a time instead of 64: each pair is two small reads, and over the network the limit is latency, not volume.
- While "Run" reads both sides it shows "Reading folders: N files" with a running bar, instead of a silent "Starting..." until the first number.
- Both versions, Electron and C#, the same way. New laws in both: a second plan from the same data does not read the files again, a changed date means a new check, an expired result is not used, a reset brings the live check back. 214 JavaScript tests and 269 C# tests, all green.

Files: `SyncGlass Setup 1.3.1.exe` and `SyncGlass-1.3.1-portable.exe` for Electron, `SyncGlass-CSharp-Setup-1.3.1.exe` and `SyncGlass-CSharp-1.3.1-portable.exe` for the C# version. The builds are not code-signed, so SmartScreen may warn on first start.

**SyncGlass 1.3.1: «Выполнить» начинает копировать сразу.** «Выполнить» сразу после предпросмотра больше не сверяет кандидатов в перемещения второй раз. На дереве автора предпросмотр уже сверил сотни тысяч перемещений, потом «Выполнить» сверял те же пары заново, и копирование началось только через полтора часа после нажатия. Теперь итоги сверки живут столько же, сколько сами сканы (15 минут): «Выполнить» берёт их и сразу копирует. Файл, который изменился и попал в новый скан, получает новый ключ и сверяется заново; «Обновить», галочка «Без мусора», ошибка и конец синхронизации сбрасывают итоги вместе со сканами. Сверка идёт по 128 пар разом вместо 64: пара - это два маленьких чтения, и по сети упирается в задержку, а не в объём. Пока «Выполнить» читает обе стороны, видно «Читаю папки: N файлов» и бегущую полосу вместо молчаливого «Начинаю…» до первой цифры. Обе версии, Electron и C#, одинаково; новые законы в обеих; 214 тестов JavaScript и 269 C#.
