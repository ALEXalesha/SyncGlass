**SyncGlass 1.3.0: big trees no longer hang, and junk folders are skipped.**

- The preview of a tree after moving folders looked frozen: the file counter stopped at the last scanned number (1 030 009 on the author's tree) for tens of minutes. The scan was done; the app was checking hundreds of thousands of move candidates by reading the start and end of both files, the destination over the network, without a word and without a way to cancel. Now the preview says "Checking moves: X of Y", the sync shows the same step, Cancel stops it, and 64 checks run at once. 200 000 moves at 5 ms per pair: 231 s of silence before, 53 s with progress every 0.15 s now. The last scan count is no longer lost.
- New "Skip junk" checkbox, on by default: `node_modules`, `.venv`, `__pycache__`, `.pytest_cache`, `.hypothesis`, `.ruff_cache` and `.mypy_cache` are not counted, not copied and not deleted on the destination (`npm ci` / `uv sync` rebuild them), and the tree does not show them. Both ways of reading the tree, the live scan and the background index, see the same. Untick it to sync everything as before.
- New laws in both versions: progress up to done = total, Cancel reaches the check, a plan with junk equals the plan of the same tree without it on both ways, the destination's junk stays. 212 JavaScript tests and 266 C# tests, all green.

Files: `SyncGlass Setup 1.3.0.exe` and `SyncGlass-1.3.0-portable.exe` for Electron, `SyncGlass-CSharp-Setup-1.3.0.exe` and `SyncGlass-CSharp-1.3.0-portable.exe` for the C# version. The builds are not code-signed, so SmartScreen may warn on first start.

**SyncGlass 1.3.0: большие деревья больше не виснут, мусорные папки пропускаются.** Предпросмотр дерева после переноса папок выглядел зависшим: счётчик файлов стоял на последнем числе скана (1 030 009 на дереве автора) десятки минут. Скан уже кончился, а программа молча и без возможности отменить сверяла сотни тысяч кандидатов в перемещения, читая начало и конец обоих файлов, приёмник по сети. Теперь предпросмотр пишет «Сверяю перемещения: X из Y», синхронизация показывает тот же шаг, «Отмена» его останавливает, сверок идёт 64 разом: 200 000 перемещений по 5 мс на пару - было 231 с тишины, стало 53 с с прогрессом каждые 0,15 с; последнее число скана больше не теряется. Новая галочка «Без мусора», по умолчанию включена: `node_modules`, `.venv`, `__pycache__`, `.pytest_cache`, `.hypothesis`, `.ruff_cache` и `.mypy_cache` не считаются, не копируются и на приёмнике не удаляются (их пересоберут `npm ci` / `uv sync`), в дереве не показываются; живой скан и фоновый индекс видят одно и то же. Снимите галочку - всё синхронизируется как раньше. Новые законы в обеих версиях; 212 тестов JavaScript и 266 C#.
